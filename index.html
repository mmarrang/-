FILE 01 / DIVISION INFORMATION

특수작전부

CLASSIFICATION / 001

특수작전부

일반적인 군사 및 경찰 조직으로 대응하기 어려운 특수능력 관련 사건을 담당한다.

CLASSIFICATION / 002

설립 목적

능력자의 등장 이후 증가한 테러, 인질 사건 및 능력 범죄에 대응하기 위해 설립되었다.

CLASSIFICATION / 003

작전 원칙

민간인 보호를 최우선으로 하며, 임무 수행 중 요원의 생존 또한 핵심 원칙으로 취급한다.

CLASSIFICATION / 004

보안 등급

본 자료는 내부 보안 자료로 분류된다. 승인되지 않은 외부 열람 및 유출을 금한다.

FILE 02 / WORLD DATABASE

세계관

WORLD / 001

능력자의 등장

약 20년 전부터 일부 인간에게 기존의 생물학적 한계를 넘어서는 특수능력이 발현되기 시작했다.

WORLD / 002

능력 범죄

능력을 이용한 테러와 범죄가 증가하면서 기존의 치안 시스템만으로는 대응하기 어려운 사건들이 발생했다.

WORLD / 003

오버로드

능력의 과도한 사용은 사용자의 신체에 부담을 일으킨다. 이를 '오버로드'라고 한다.

WORLD / 004

현재

특수작전부는 국가의 최전선에서 능력자와 관련된 고위험 사건을 처리하고 있다.
